Pane

Android Emulator Mirror for Mac

The Android emulator in a clean Mac window.

Pane shows a running emulator inside a device frame it draws. Click, scroll and type as you would on the phone.

Download for Mac Source on GitHub Release notes

Free and open source. For macOS 15 or later.

A real device frame

The emulator sits in a frame drawn to fit its screen. Clicks, scrolls and keys go straight to it, and the power and volume buttons work.

Tools for checking layouts

Inspect layout shows a view's frame, size and id in dp. Measure snaps to view edges. Pick colour copies a pixel's hex value.

Drop to install

Drop an app on the screen and Pane says whether it's new, an update or older before you let go. Other files go to the Download folder.

Screenshots and recordings

Save or copy screenshots, with the frame if you want it. Recordings show a timer and can be exported as a GIF.

Sizes you know

Physical Size, Point Accurate, Pixel Accurate and Fit Screen, like the iOS Simulator. Each emulator gets its own window.

Shared clipboard

Text you copy on the device reaches the Mac while Pane is in front. Command-V pastes the Mac's text on the device.

What it needs

macOS 15 or later, and the Android SDK with its emulator and at least one virtual device. Pane starts an emulator without its own window, or attaches to one already running. It works with the Android emulator only, not physical phones or the iOS Simulator.

Emulator 37.3.9 or later is recommended. The current stable build, 37.2.13, can crash while anything streams its screen. Install the beta with sdkmanager --channel=1 emulator.

Show all emulators in Pane

An optional setting, off by default. When it's on, an emulator started anywhere, such as from Expo or a terminal, opens in Pane without its own window. It changes your shell setup:

  • It creates a wrapper SDK folder at ~/Library/Android/pane-sdk that links to your real SDK. Only the emulator launcher is replaced.
  • It adds a small marked block to your fish and zsh config files, pointing ANDROID_HOME at the wrapper. Pane backs up each file first.

Turn it off and Pane removes the block and the folder. If Pane is missing, the wrapper runs the real emulator unchanged. While it's on, install SDK packages from Android Studio, since sdkmanager from your shell would write into the wrapper folder.

Private by design

No account and no analytics. Pane only goes online to check for its own updates. It isn't sandboxed, because it reads the emulator's files to find it. Releases are signed with a Developer ID and notarized by Apple, and the code is on GitHub under GPL-3.0.
