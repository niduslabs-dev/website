Pane

by Nidus Labs

The Android emulator in a clean Mac window.

Pane shows a running emulator inside a device frame it draws. Click, scroll and type as you would on the phone.

Download for Mac Source on GitHub

Free and open source. For macOS 15 or later.

What it does

  • Shows the emulator in one window, inside a frame drawn to fit its screen. Clicks, scrolls and keys go to the emulator.
  • The power and volume buttons on the frame work. Click them.
  • Inspect layout shows a view's frame, size and id in dp. Measure draws a line between two points and snaps to view edges. Pick colour copies a pixel's hex value.
  • Drop an app on the screen to install it. Pane says whether it's new, an update or older before you let go. Other files go to the device's Download folder.
  • Text you copy on the device reaches the Mac while Pane is in front. Command-V in Pane pastes the Mac's text on the device.
  • Saves or copies screenshots, with the device frame if you want it. Recordings show a timer while they run and can be exported as a GIF.
  • Window sizes like the iOS Simulator: Physical Size, Point Accurate, Pixel Accurate and Fit Screen.
  • Click the device name to switch emulators, or open another one in a new window. Each emulator gets one window.
  • Starts an emulator without its own window, or attaches to one that is already running.

What it needs

  • macOS 15 or later.
  • The Android SDK with its emulator installed, and at least one virtual device.
  • Emulator 37.3.9 or later is recommended. The current stable build, 37.2.13, can crash while anything streams its screen. Install the beta with sdkmanager --channel=1 emulator.

Pane works with the Android emulator only. It does not show physical phones or the iOS Simulator.

Show all emulators in Pane

This setting is in Pane's Settings. It is optional and off by default. When it is on, an emulator started anywhere, such as from Expo or a terminal, opens in Pane without its own window.

It changes your shell setup, so here is what it does:

  • It creates a wrapper SDK folder at ~/Library/Android/pane-sdk. The folder links to your real SDK. Only the emulator launcher is replaced.
  • It adds a small marked block to your fish and zsh config files. The block points ANDROID_HOME at the wrapper folder. Pane backs up each file first.

Turn the setting off and Pane removes the block and the folder. If Pane is missing, the wrapper runs the real emulator unchanged.

While the setting is on, install SDK packages from Android Studio. Running sdkmanager from your shell would write into the wrapper folder.

Good to know

  • No account and no analytics. Pane only goes online to check for its own updates.
  • Pane is not sandboxed. It has to read the emulator's files to find and connect to it.
  • Releases are signed with a Developer ID and notarized by Apple.
  • Pane updates itself.
  • The code is on GitHub under GPL-3.0.
