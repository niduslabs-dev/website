Drop

DMG Installer for Mac

Install Mac apps in one click. No mounting, no dragging, no ejecting.

When a disk image finishes downloading, Drop shows the app, its version and who made it. Click Install and it's in Applications.

Download for Mac Source on GitHub

Free and open source. For macOS 15 or later.

It notices new downloads

A small panel slides in at the top right when a .dmg lands in Downloads. It never takes over what you're typing in.

You see who made it

The developer's name, and whether Apple has checked the app, before you install. Damaged apps are refused.

Fast

Drop reads the disk image itself and has the app ready before you click. Big apps install in about a second.

Out of the way

No Dock icon, no menu bar icon. About 17 MB of memory and no CPU while it waits.

macOS stays in charge

Apps keep their downloaded-from-the-internet record, so Gatekeeper still checks them the first time they open.

Updates and licences

It replaces an older copy and sends it to the Trash, and shows a disk image's licence before installing.

Private by design

No account and no analytics. Drop sends nothing anywhere. It only checks GitHub for its own updates. Releases are signed with a Developer ID and notarized by Apple.
